## お約束できないこと / What we cannot promise

個人開発のため、以下をご了承ください。

- **返信の時期はお約束できません。** 返信できない場合もあります。
- **個別の使い方サポートは行っていません。**
- 報告いただいた不具合の修正時期・修正の可否はお約束できません。

回答は**公開の場で**行います。同じ問題を抱えた方が後から読めるようにするためです。

This is a solo project:

- **No response time is promised**, and a reply is not guaranteed.
- **No individual usage support** is provided.
- Fixes are not guaranteed, nor is any timeline.

Replies are given **in public** so that others with the same problem can find them.

## 不具合報告に必ず含めてほしいもの / Please always include

これが無いと調査できず、そのまま閉じることがあります。

1. **アプリのバージョン**（設定画面 or タイトルバーに表示）
2. **OS**（Windows 10 / 11）
3. **再現手順**（1. → 2. → 3. の形で）
4. **期待した動作 / 実際の動作**
5. **DevTools のコンソールエラー**（`Ctrl + Shift + I` → Console タブ → 赤い行のスクリーンショット）

Without these we cannot investigate and may close the issue.

1. **App version**
2. **OS**
3. **Steps to reproduce** (numbered)
4. **Expected vs actual behaviour**
5. **Console errors** (`Ctrl + Shift + I` → Console → screenshot of red lines)
